# court-ocr — распознавание судебных приказов в CSV

Программа распознаёт сканы судебных приказов (PDF/изображения) встроенным
**Tesseract**, автоматически **исправляет поворот** страниц (в т.ч. на 45° и 90°)
и складывает распознанный текст **построчно в CSV**. Работает в выбранное число **потоков**.

- рендер PDF без установки poppler (используется PyMuPDF);
- Tesseract «вшит» в проект (папка `tesseract/`) — отдельная установка не нужна;
- авто-поворот: 90/180/270° — по OSD Tesseract; ~45° и перекос сканера — по
  проекционному профилю (без OpenCV);
- распознавание русского языка (`rus`, точная модель `best`), извлечение полей приказа;
- построчный CSV (`page;line_id;line`) в кодировке **Windows-1251**.

## Готовый .exe (без установки Python)

В папке `dist/court-ocr/` собрано автономное приложение. **Движок Tesseract вшит
в сам exe**, а **языковая модель вынесена в отдельную папку** `tessdata/` (её можно
заменить, не пересобирая программу). Структура:

```
court-ocr/
  court-ocr.exe        ← запускать это (движок Tesseract внутри)
  tessdata/            ← языковая модель rus + osd (внешняя, сменяемая; не удалять)
  input/               ← сюда кладём PDF/сканы
  output/              ← сюда попадает результат (папка на каждый документ)
  ЗАПУСК.txt           ← краткая инструкция
```

Порядок работы: положить PDF в `input/` → запустить `court-ocr.exe` → программа
сама определяет **максимум потоков** (Enter — взять максимум) → документы
обрабатываются **по одному**, и как только документ готов, его результат сразу
пишется в `output/` двумя файлами (без вложенных папок):

- `<имя>.csv` — построчный текст (`page;line_id;line`, Windows-1251);
- `<имя>.pdf` — **распознанный PDF** (с невидимым текстовым слоем: по нему можно
  искать и копировать текст; страницы уже в правильной ориентации). Изображение —
  чёрно-белое 1-битное (факс-сжатие), поэтому файл компактный (в ~10 раз легче
  серого 300 dpi) без потери точности распознавания.

Не закрывая программу, можно докладывать новые файлы в `input/` и нажимать Enter.
Держите `court-ocr.exe` и папку `tessdata/` вместе. Запускайте из папки с правом
на запись (не из `Program Files`).

Пересобрать exe из исходников (движок внутрь, модель снаружи):

```
pip install pyinstaller
mkdir _engine && copy tesseract\tesseract.exe _engine\ && copy tesseract\*.dll _engine\
python -m PyInstaller --noconfirm --onefile --console --name court-ocr ^
  --icon icon.ico --add-data "_engine;tesseract" --paths . app.py
```

затем рядом с `dist/court-ocr.exe` создать папку `tessdata/` с `rus.traineddata` и
`osd.traineddata`, а также `input/` и `output/`.

## Запуск из исходников (Python)

## Установка

Нужен Python 3.9+ (проверено на 3.11).

```bat
cd court-ocr
pip install -r requirements.txt
python setup_tesseract.py
```

`setup_tesseract.py` один раз скачивает официальную сборку Tesseract 5.x
(UB-Mannheim, лицензия Apache-2.0) и модели `rus` + `osd` в папку
`tesseract/`. После этого интернет для работы не нужен.

Если Tesseract уже установлен в системе — можно только докачать модели:
```bat
python setup_tesseract.py --data-only         REM модели в ./tesseract/tessdata
```
и запускать программу с `--tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe"`.

## Запуск

```bat
REM обработать все PDF/изображения в папке, 8 потоков
python ocr_court.py "C:\сканы" -o result.csv -j 8

REM один файл
python ocr_court.py "228_20240405ЛАО_ССП_28.pdf" -o result.csv

REM рекурсивно по подпапкам + сохранить распознанный текст в .txt
python ocr_court.py "C:\сканы" -r --save-text txt -o result.csv
```

Каждая распознанная строка текста → отдельная строка CSV (`page;line_id;line`).
Поддерживаются `.pdf`, `.png`, `.jpg/.jpeg`, `.tif/.tiff`, `.bmp`, `.webp`.

## Ключи

| Ключ | Назначение | По умолчанию |
|------|------------|--------------|
| `-o, --output` | файл CSV | `court_ocr_result.csv` |
| `-j, --threads` | число потоков | число ядер CPU |
| `-r, --recursive` | искать в подпапках | нет |
| `--dpi` | DPI рендера PDF | `300` |
| `--binarize` | бинаризация (Otsu) перед OCR | нет |
| `--max-skew` | макс. остаточный перекос после OSD, ° | `10` |
| `--wide` | диапазон широкого поиска угла (для ~45°), ° | `46` |
| `--delimiter` | разделитель CSV | `;` |
| `--no-raw-text` | не сохранять колонку с полным текстом | нет |
| `--save-text DIR` | сохранять текст каждой страницы в `.txt` | нет |
| `--tesseract PATH` | путь к `tesseract.exe` | встроенный/PATH |
| `--lang` | языки Tesseract | `rus` |
| `--tessdata-dir DIR` | своя папка с моделями `.traineddata` | встроенная |
| `--psm` / `--oem` | режимы Tesseract | `6` / `1` |
| `--list` | только перечислить найденные файлы | — |

## Формат CSV

Построчный: одна строка распознанного текста = одна строка CSV. Три колонки:

| Колонка | Значение |
|--|--|
| `page` | номер страницы |
| `line_id` | номер строки в пределах страницы (с 1) |
| `line` | распознанный текст строки |

Кодировка — **Windows-1251** (cp1251), разделитель — `;`. Символы вне cp1251
заменяются на `?`. Пример:

```
page;line_id;line
1;3;Судебный участок № 57 в Ленинском судебном районе в городе Омске
1;7;СУДЕБНЫЙ ПРИКАЗ
```

## Как исправляется поворот

1. **OSD Tesseract** (`--psm 0`) уверенно определяет 0/90/180/270° и переворот
   «вверх ногами». Кратные 90° применяются без интерполяции (лоссless).
2. **Проекционный профиль** (максимум дисперсии суммы по строкам) убирает
   остаточный перекос сканера.
3. Если OSD не уверен (типично для листа, повёрнутого на **~45°**) — включается
   **широкий поиск угла** (±46°); после выравнивания OSD запускается повторно,
   чтобы снять неоднозначность «прямо/вверх ногами». Если после узкого поиска
   перекос упёрся в границу окна — программа тоже переходит к широкому поиску
   (страховка от «ложного 0°» OSD на 45°).

Колонка `rotation_deg` показывает, что именно было применено, например
`OSD 180° + перекос +0.7°` или `OSD 0° → широкий -45.1°`.

## Точность и настройка

- Стоит точная русская модель (`tessdata_best`) — она даёт меньше ошибок
  распознавания. Само число `ocr_confidence` при этом остаётся ~90% (его «топят»
  печати, штрихкоды и рукописные пометки, а не шрифт текста).
- Для грязных или бледных сканов попробуйте `--binarize` и/или `--dpi 400`.
- Другие модели можно подключить, не трогая основную: положите `.traineddata` в
  отдельную папку и укажите `--tessdata-dir <папка>` (папка `configs` в ней не нужна).
- Если нужен латинский текст (латиница в названиях) — верните английскую модель:
  `python setup_tesseract.py --data-only --langs eng --best` и запускайте с
  `--lang rus+eng`.

## Замечания

- Извлечение полей настроено на судебные приказы о взыскании задолженности
  (ЖКХ/теплоснабжение). На других документах поля могут не заполниться, но текст
  всё равно попадёт в `raw_text`, а страница не «уронит» весь прогон.
- Tesseract и языковые модели распространяются под лицензией Apache-2.0.
