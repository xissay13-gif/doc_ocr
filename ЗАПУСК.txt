court-ocr — распознавание судебных приказов
============================================

БЫСТРЫЙ СТАРТ
-------------
1. Запустите  Мониторинг.bat
2. Кладите PDF и сканы в папку  input
3. Забирайте результат из папки  output

Папки input и output создаются сами при первом запуске.
Каждый документ распознаётся сразу, как только попал в папку.
Остановить: Ctrl+C (на вопрос "Terminate batch job (Y/N)?" ответьте Y)
или просто закройте окно.


ЧТО ПОЛУЧАЕТСЯ
--------------
На каждый входной файл в папке output появляются два файла:

  <имя>.csv   распознанный текст построчно: page;line_id;line
              кодировка Windows-1251, разделитель ";" — открывается в Excel

  <имя>.pdf   тот же скан, но с текстовым слоем: по нему можно искать
              и копировать текст, страницы уже развёрнуты как надо


КАК ЗАДАТЬ СВОИ ПАПКИ
---------------------
Способ 1. Перетащите нужную папку мышью прямо на Мониторинг.bat —
          она станет входной.

Способ 2. Откройте Мониторинг.bat Блокнотом и впишите пути в начале файла:

              set "INPUT=D:\Сканы\входящие"
              set "OUTPUT=D:\OCR"

Способ 3. Создайте рядом с court-ocr.exe файл court-ocr.json:

              {
                "input_dir":  "D:/Сканы/входящие",
                "output_dir": "//server/share/ocr",
                "threads": 8
              }

          Внимание: в этом файле пишите пути через прямой слэш "D:/Сканы"
          или удваивайте обратный "D:\\Сканы" — таковы правила JSON.

Пути могут быть сетевыми. Если задано в нескольких местах сразу,
главнее то, что выше: перетаскивание > Мониторинг.bat > court-ocr.json.


НУЖНО МЕНЮ, А НЕ СРАЗУ МОНИТОРИНГ
---------------------------------
Запустите court-ocr.exe — там же есть разовый проход по папке,
смена папок и числа потоков.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
"не найдена языковая модель"
    Рядом с court-ocr.exe должна лежать папка tessdata,
    а в ней файлы rus.traineddata и osd.traineddata. Не удаляйте её.

Программа не запускается или ругается на права
    Не запускайте из Program Files: нужна папка с правом на запись.
    Подойдут, например, C:\court-ocr или рабочий стол.

Файл долго не подхватывается
    Так и задумано: программа ждёт, пока файл допишется до конца,
    иначе распознала бы половину документа.

Документ уже обработан, а нужно заново
    Удалите файл .court-ocr-state.json из папки результатов
    (это память о том, что уже сделано).


Tesseract и языковые модели распространяются по лицензии Apache-2.0.
